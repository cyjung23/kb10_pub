# S1-05: 사이트 운영·작성 상시 원칙

**최종 갱신:** 2026-07-29

본 문서는 KB10의 지속적인 운영·콘텐츠 작성 원칙(상시 기준)을 정리한다. 일회성 의사결정은 s5-decisions 로그에 기록하고, 그 결정에서 도출된 "계속 지켜야 할 규칙"은 이 문서에 모은다. 각 원칙에는 근거 DEC 번호를 상호참조로 부기한다.

원칙과 결정의 관계: DEC 로그는 "언제·왜 그렇게 정했는가"(이력)를 남기고, 본 문서는 "지금 지켜야 할 규칙"(현행 기준)을 남긴다.

## 1. 법적·규제 준수

의료법상 의료광고 규제와 환자 유인·알선 금지(의료법 제27조 제3항)를 회피하기 위한 상시 기준. 병원 정보를 "대가 없이 객관적으로 나열"하면 위법이 아니라는 것이 실무·판례의 이해이나, 아래 조건을 하나라도 어기면 유인·알선 또는 의료광고로 해석될 위험이 있다.

- 순위·비교·과장 표현 배제: "최고 병원 10선" 같은 순위·추천이 아니라, "서울에서 OO 시술을 받을 수 있는 병원 정보"처럼 객관적 나열로 작성. 전후사진·환자후기도 배제.
- 중개 기능 배제: 예약·상담·결제 등 환자를 특정 병원으로 연결·송객하는 기능을 두지 않음. 정보 제공에서 멈춘다.
- 대가 수령 금지: 어떤 병원으로부터도 광고 의뢰비·실적 연동 수수료·인센티브를 받지 않음. 대가 수령이 확인되면 유인·알선으로 판단될 수 있음.
- 근거 판례: 대법원 2010도1763(대가 없는 정보 제공 = 합법), 대법원 2018도20928(대가성 유인·알선 = 위법).
- 상호참조: DEC-007(순위·비교 배제 결정)

## 2. 정체성·독립성

- KB10의 정체성: 한국을 방문하는 외국인 여행자를 위한 K-뷰티 미용의료(피부과 중심) 정보 큐레이션 사이트. 여행 맥락(짧은 일정·다운타임·타이밍 등)의 검색 의도를 충족하는 것이 핵심.
- 독립성: 특정 병원과 법적·자본적 관계가 없는 독립 사이트. SCP(참의원 연계)와 명확히 구분된다. 어떤 병원의 광고 의뢰도 받지 않으며, KB10의 콘텐츠는 병원 요청 광고가 아니다.
- SCP와의 관계: 기술 체계·문서 규칙은 SCP를 승계하되, SCP DB 원문은 그대로 쓰지 않고 KB10 관점(여행자용)으로 리라이팅한다.
- 상호참조: DEC-002(K-beauty 정보 큐레이션 정체성), DEC-007(법적 기준선·SCP 승계)

## 3. 콘텐츠 작성

- 검색 의도 기반: 여행자 커뮤니티에서 실제로 반복되는 롱테일 검색 의도(예: 짧은 일정용 원타임 시술, 비행 전·다운타임 없는 시술, A vs B 비교)를 우선한다.
- 키워드 1:1 원칙: 한 페이지는 하나의 핵심 키워드/검색 의도를 담당한다. 중복 콘텐츠를 만들지 않는다.
- 제목 규칙: "Best/Top" 등 순위·과장 표현을 제목에서 회피한다. 연도(예: 2026)는 제목·본문·meta에만 넣고 URL에는 넣지 않는다(신선도 유지, URL 안정성 확보).
- SCP DB 리라이팅: SCP의 시술·병원 데이터를 그대로 복제하지 않고 여행자 관점으로 재작성한다(중복 콘텐츠 회피).
- 상호참조: DEC-005(제목·연도 규칙), DEC-011(영어권 관광객 대상), DEC-012(키워드 1:1 매핑), DEC-013(검색 의도 기반 페이지)

## 4. 다국어·SEO

- 언어 정책: English 기본(defaultLocale=en) + 한국어. /en/, /ko/ 하위 폴더 라우팅.
- locale 자동감지 비활성화: next-intl localeDetection=false. 루트(/) 접속 시 기본 en으로 리다이렉트(자동감지의 크롤러·SEO 부작용 회피).
- 언어별 독립 페이지: 같은 콘텐츠의 단순 번역판이 아니라, 언어별로 독립된 관점의 페이지를 작성한다. 따라서 언어 짝(1:1)이 없을 수 있다.
- hreflang 정책: 언어 짝이 없는 페이지는 hreflang 언어 짝을 연결하지 않는다. 사용자용 언어 전환 링크와 크롤러용 hreflang은 별개로 취급한다.
- 상호참조: DEC-004(English 기본+한국어·hreflang), DEC-009(locale 자동감지 비활성화), DEC-014(언어별 독립 페이지·hreflang 미연결)
